SeeBus experiment suite

32 paired worlds per sweep point · policies: Static, Historical, Sensor, Hybrid · baseline Static

Fleet pressure

Vary the size of the shared bus pool while keeping demand, routes, sensor quality, and the nominal static timetable unchanged.

One-off event frequency

Vary the expected number of unexpected station demand spikes per network-day. Internally this is converted to the equivalent per-station/day event probability.

Occupancy estimation accuracy

Vary Gaussian occupancy-estimation error while keeping reporting quantization fixed at 1 percentage point. Lower values mean more accurate station occupancy estimates.

Paired robustness views use the same synthetic world at every impairment level. Benefit over Historical asks whether imperfect sensing is still worth using; degradation shows how much is lost relative to the 0% impairment point.

Packet dropout

Vary independent sensor-packet loss. When a packet is lost, the server continues using the last successfully received occupancy reading until a newer packet arrives.

Paired robustness views use the same synthetic world at every impairment level. Benefit over Historical asks whether imperfect sensing is still worth using; degradation shows how much is lost relative to the 0% impairment point.

Hybrid sensor/history weight

Vary how Hybrid combines normalized historical-demand pressure and live sensor pressure. A sensor weight of 0 is history-only; 1 is sensor-only; intermediate values blend the two signals.
